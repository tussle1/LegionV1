# LEGION

A Roblox client fork and rebrand owned and maintained by **Xylen**.

## Provenance

LEGION is a rebranded fork, not a clean-room implementation. The current `loadstring` entrypoint points to the upstream Vape V4 script, and this repository's bootstrap downloads runtime code from [7GrandDadPGN/VapeCompiled](https://github.com/7GrandDadPGN/VapeCompiled). LEGION branding and fork maintenance are by Xylen; upstream code is not claimed as original work by Xylen.

The branding changes are in the checked-in source. The current entrypoint and build workflow still target upstream hosting, so a live build will not use these changes until it is built and hosted through a destination you control.
